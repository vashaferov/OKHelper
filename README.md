# ok-helper-tui

Кроссплатформенный терминальный помощник для работы с треками и путевыми
точками (`.gpx`, `.plt`, `.wpt`). Умеет:

- переименовывать файлы из «скачанных» имён в формат `ГГГГММДД_Позывной`
  с нормализацией позывного;
- следить за папкой загрузок и предлагать перенести новые файлы в нужную
  директорию;
- просматривать содержимое папок на FTP-сервере и **удалять файлы**;
- загружать файлы на FTP-сервер;
- проверять имена по правилам, заданным в проекте.

Программа работает в терминале: Linux, macOS, Windows.

## Возможности

### Проверка и переименование имён

Для файлов `.gpx` и `.plt` сервис ожидает формат:

```
ГГГГММДД_Позывной
```

**Нормализация позывного:**

- первая буква позывного — заглавная (`lisa` → `Lisa`);
- хвостовой номер (цифры в конце) — минимум 2 разряда, разделитель
  `_`/`-` перед ним убирается:
  - `lisa_1` → `Lisa01`
  - `lisa1` → `Lisa01`
  - `lisa_2` → `Lisa02`
  - `lisa-1` → `Lisa01`
  - `lisa_12` → `Lisa12`
  - `lisa_001` → `Lisa001`
- если база **уже заканчивается цифрой**, значит номер уже в ней —
  хвостовая группа `_N`/`-N` не трогается:
  - `Lisa01_1` → `Lisa01_1`
  - `Lisa01_12` → `Lisa01_12`
  - `lisa01_1` → `Lisa01_1` (капитализируется только первая буква)

Примеры итоговых переименований:

```
20260923_lisa.gpx            → 20260923_Lisa.gpx
20260923_lisa_1.gpx          → 20260923_Lisa01.gpx
2026-09-17_11-55_бабушка.gpx → 20260917_Babushka.gpx
2026-09-17_11-55_babushka (Копия 2).gpx
                             → 20260917_Babushka_Kopiya02.gpx
20260923_Lisa01_1.gpx        → (уже валидно, без изменений)
```

Рядом с «плохим» файлом в дереве появляется кнопка:

- **`[Правка]`** (зелёная) — имя нормализуется однозначно, клик переименует;
- **`[Правка]`** (жёлтая) — дата найдена, позывной осмысленный;
- **`[Правка?]`** (оранжевая) — похоже на заглушку, клик откроет редактор.

Двойной клик по имени файла открывает редактор переименования (аналог F7).

**Дата из содержимого `.gpx`.** Если в имени `.gpx` дата отсутствует,
сервис читает последние ~256 КБ файла, находит самую позднюю временную
метку `<time>` и использует её как дату.

Для `.wpt` допустимо только имя вида `Waypoints_ГГГГММДД`.

Файлы `<1-4 цифры>m.gpx` (например, `100m.gpx`) не проверяются.

### Две вкладки в правой панели

Правая панель имеет две вкладки — **Файлы** и **FTP**. Переключаются
клавишами **Ctrl+→ / Ctrl+←** или кликом по таб-бару.

Если чек-бокс «Отслеживать папку из вкладки «Файлы»» включён, при
переходе на вкладку FTP сервис ищет выше по дереву папку вида
`ГГГГ-ММ-ДД_Место`, подставляет её и подключается.

### Мониторинг папки загрузок

Если в конфиге включён `watch_downloads = true`, сервис следит за папкой
загрузок. Как только там появляется новый файл — открывается модалка:

- **Enter / Y** — перенести в текущую открытую директорию;
- **N / Esc** — пропустить.

### Отправка и удаление на FTP

**Отправка (F12 или `[⇪]`):**

- `.plt` — с корректным (нормализованным) именем;
- `.wpt` — только `Waypoints_ГГГГММДД`;
- `.gpx` — **только** `<1-4 цифры>m.gpx`;
- файлы из папки `10-Tracks` — запрещены;
- папка назначения обязательна.

**Удаление (Delete или `[✕]`):**

- открывается модальное окно подтверждения;
- работает только при `ftp_readonly = false`.

### Режим эмуляции FTP

`ftp_readonly = true` — сервис реально подключается, читает папки, но
**не создаёт** их, **не загружает** и **не удаляет** файлы.

## Клавиши

| Клавиша | Действие |
|---|---|
| `F1` | Справка |
| `F2` | Фильтр |
| `F3` | Открыть файл |
| `F4` | Сортировка |
| `F5` | Исправить все |
| `F6` | Rescan / обновить FTP |
| `F7` | Переименовать |
| `F8` | Очередь Загрузок |
| `F9` | Мониторинг Загрузок |
| `F10` | Настройки |
| `F11` | Очистить журнал |
| `F12` | Загрузить на FTP |
| `Delete` | Удалить на FTP (с подтверждением) |
| `Ctrl+→ / Ctrl+←` | Переключить вкладку |
| `Ctrl+Z` | Отмена |
| `Ctrl+C / Ctrl+Q` | Выход |

## Установка

Требуется **Python 3.11+** и терминал с поддержкой 256 цветов и мыши.

```bash
git clone https://github.com/vashaferov/OKHelperTUI.git
cd ok-helper-tui
python -m venv .venv

# Linux / macOS:
source .venv/bin/activate
# Windows (PowerShell):
# .venv\Scripts\Activate.ps1

pip install -r requirements.txt
python main.py
```

Портативная сборка `.exe` для Windows — в артефактах GitHub Actions
(`ok-helper-tui-windows`).

## Настройка

Настройки в TOML:

| ОС | Путь |
|---|---|
| Linux | `~/.config/ok-helper-tui/config.toml` |
| macOS | `~/Library/Application Support/ok-helper-tui/config.toml` |
| Windows | `%APPDATA%\ok-helper-tui\config.toml` |

```toml
root_dir        = '~/Tracks'
downloads_dir   = '~/Downloads'
watch_downloads = false
theme           = 'auto'

ftp_host        = 'ftp.example.com'
ftp_port        = 21
ftp_user        = 'username'
ftp_password    = 'secret'
ftp_path        = '/upload'
ftp_readonly    = false
```

Пути пишите в **одинарных** кавычках, если они содержат `\`:

```toml
root_dir = 'C:\Users\you\Tracks'   # правильно
root_dir = "C:\Users\you\Tracks"   # ошибка TOML
```

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest -v
```

Маркеры: `analyzer`, `ftp`, `translit`, `folder`, `path_walk`, `upload`,
`smoke`. Пример: `pytest -m "ftp and smoke"`.

Allure-отчёт:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

CI/CD (`.github/workflows/ci.yml`):

1. Тесты на Ubuntu и Windows, Python 3.11 и 3.12, с Allure.
2. Публикация Allure-отчёта в артефактах и на GitHub Pages.
3. Сборка `.exe` для Windows.
