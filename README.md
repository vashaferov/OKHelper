# ok-helper-tui

Кроссплатформенный терминальный помощник для работы с треками и путевыми
точками (`.gpx`, `.plt`, `.wpt`). Умеет:

- переименовывать файлы из «скачанных» имён в формат `ГГГГММДД_Позывной`;
- создавать локальные папки прямо из дерева файлов;
- переносить локальные файлы между папками;
- копировать имя выделенного элемента в буфер;
- синхронизировать статус «уже на FTP» между локальной папкой и сервером;
- следить за папкой загрузок и предлагать перенести новые файлы;
- просматривать, обновлять и удалять файлы на FTP-сервере;
- загружать файлы на FTP-сервер;
- проверять имена по правилам, заданным в проекте.

Работает в терминале: Linux, macOS, Windows.

## Возможности

### Очистка журнала

**Ctrl+L** — очистить журнал. Основная комбинация.
**F11** тоже работает, но в Windows Terminal и большинстве
Linux-эмуляторов эта клавиша перехватывается терминалом и до
приложения не доходит.

### Прокрутка

Прокрутка работает во всех окнах:

- **Журнал** — колесо мыши, `PageUp` / `PageDown`, `Home` / `End`.
  Новые записи автоматически подматываются к нижней строке.
- **Дерево файлов** — `↑` / `↓`, `PageUp` / `PageDown`, колесо мыши.
- **FTP-список** — `↑` / `↓`, колесо мыши.
- **Окно справки (F1)** — `PageUp` / `PageDown`, `↑` / `↓`,
  `Home` / `End`.

### Перенос файлов между локальными папками

- **Ctrl+X** из главного окна — открывает перенос для выделенного файла;
- **двойной клик по файлу** (или **F7**) → в открывшейся модалке
  «Переименование» нажать кнопку **`[⇢ Перенести в другую папку]`**.

В модалке переноса введите путь назначения — абсолютный или
относительный. Поддерживается `~`. Enter — файл переносится через
`shutil.move`. Отмена — **Ctrl+Z**.

### Синхронизация с FTP

После загрузки списка файлов из папки на вкладке **FTP** сервис
помечает локальные файлы с такими же именами зелёной галочкой **`✓`**
в дереве. Это означает: файл уже залит на сервер.

Сверка выполняется:

- **при каждой загрузке листинга с FTP** — в том числе через F6
  и кнопку `[↻]`;
- **после каждой успешной загрузки файла на FTP** через F12 —
  залитый файл сразу помечается галочкой в дереве, без ручного
  обновления списка на FTP.

Условия срабатывания:

- папка на FTP — одноуровневая (`2026-09-23_Moscow`, без `/`);
- имя родительской папки локального файла совпадает с именем папки
  на FTP;
- имя самого файла присутствует в листинге FTP.

Если в дереве есть хотя бы один «залитый» файл, в статус-баре
появляется счётчик `✓ на FTP: N`.

### Окно справки (F1)

Открывается по **F1**. Содержимое длинное — текст прокручивается.
Чек-бокс `[x] Показывать при старте` вверху окна переключается кликом
или клавишей `Пробел`.

#### Первый запуск

- **Первый запуск.** Автоматически открывается окно **настроек (F10)**.
  После его закрытия сразу открывается окно **подсказок (F1)**.
- **Последующие запуски.** Открывается окно подсказок (F1), если
  включён чек-бокс `[x] Показывать при старте`.

### Создание папок

Кнопка **`[+ Папка]`** показывается в дереве **на каждом уровне**.
Клик открывает модалку создания новой папки. Альтернатива — **Ctrl+N**.

#### Особенность создания в корне

Если папка создаётся в корне (`root_dir` из конфига):

- имя предзаполняется текущей датой `ГГГГ-ММ-ДД_`;
- появляется чек-бокс `[ ] Создать внутри 10-Tracks`.

### Копирование имени (Ctrl+Y)

Копирует имя выделенного элемента (файла **или папки**) в системный
буфер. Работает на обеих вкладках.

Копирование через системные утилиты:

| ОС | Инструмент |
|---|---|
| Linux | `wl-copy` / `xclip` / `xsel` |
| macOS | `pbcopy` |
| Windows | `clip` |
| Любая ОС | `pyperclip` (если установлен) |

### Проверка и переименование имён

Для `.gpx` и `.plt` сервис ожидает формат `ГГГГММДД_Позывной` с
нормализацией позывного:

- первая буква — заглавная (`lisa` → `Lisa`);
- хвостовой номер (1–4 цифры после букв) — минимум 2 разряда,
  разделитель `_`/`-` перед ним убирается. Номер может быть как в
  конце позывного, так и в середине (с суффиксом после него):
  - `lisa_1` → `Lisa01`
  - `lisa1` → `Lisa01`
  - `lisa-1` → `Lisa01`
  - `lisa_12` → `Lisa12`
  - **`Lisa_03_Test` → `Lisa03_Test`**
  - **`Lisa_04_1` → `Lisa04_1`**
- если база уже оканчивается цифрой (`Lisa01_1`), хвостовая группа
  не трогается.

Кнопки в дереве:

- **`[Правка]`** (зелёная) — имя нормализуется однозначно;
- **`[Правка]`** (жёлтая) — дата найдена, позывной осмысленный;
- **`[Правка?]`** (оранжевая) — заглушка, откроет редактор.

Двойной клик по имени файла открывает редактор переименования.
Внутри — кнопка переноса файла в другую папку.

**Дата из содержимого `.gpx`.** Если в имени `.gpx` даты нет, сервис
читает последние ~256 КБ файла и берёт дату из последней `<time>`.

Для `.wpt` — только `Waypoints_ГГГГММДД`. Файлы `<1-4 цифры>m.gpx`
(`100m.gpx`) не проверяются.

### Две вкладки в правой панели

Вкладки **Файлы** и **FTP** переключаются **Ctrl+→ / Ctrl+←** или
кликом. Чек-бокс «Отслеживать папку из вкладки «Файлы»» — при переходе
на FTP сервис ищет выше по дереву папку `ГГГГ-ММ-ДД_Место` и
подключается.

### Обновление содержимого FTP

В заголовке панели FTP есть кликабельная кнопка **`[↻]`** — обновляет
список файлов текущей папки. Дублируется клавишей **F6** (на вкладке
FTP).

### Отправка, обновление и удаление на FTP

**Отправка (F12 или `[⇪]`):**

- `.plt` — с корректным именем;
- `.wpt` — только `Waypoints_ГГГГММДД`;
- `.gpx` — **только** `<1-4 цифры>m.gpx`;
- файлы из папки `10-Tracks` — запрещены;
- папка назначения обязательна.

**Удаление (Delete или `[✕]`):** только при `ftp_readonly = false`,
с модальным подтверждением.

### Режим эмуляции FTP

`ftp_readonly = true` — сервис подключается, читает папки, но **не
создаёт**, **не загружает** и **не удаляет** файлы.

## Клавиши

| Клавиша | Действие |
|---|---|
| `F1` | Справка (с прокруткой) |
| `F2` | Фильтр |
| `F3` | Открыть файл |
| `F4` | Сортировка |
| `F5` | Исправить все |

| `F7` | Переименовать (открывает двойной клик по файлу) |

| `F10` | Настройки |

| `F11` | Очистить журнал (если терминал пропускает) |

| `Ctrl+N` | Создать папку |
| `Ctrl+X` | Перенести выделенный файл в другую локальную папку |
| `Ctrl+Y` | Копировать имя выделенного |
| `Ctrl+→ / Ctrl+←` | Переключить вкладку |

| `Ctrl+C / Ctrl+Q` | Выход |

| Клик по `[+ Папка]` | Создать папку |

| Колесо мыши | Прокрутка журнала / дерева / FTP |

## Установка

Требуется **Python 3.11+** и терминал с поддержкой 256 цветов и мыши.

```bash
git clone https://github.com/<ваш-логин>/ok-helper-tui.git
cd ok-helper-tui
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Опционально для буфера обмена:

```bash
pip install pyperclip
```

Портативная сборка `.exe` для Windows — в артефактах GitHub Actions
(`ok-helper-tui-windows`).

## Настройка

Настройки в TOML:

| ОС | Путь |
|---|---|
| Linux | `~/.config/ok-helper-tui/config.toml` |
| macOS | `~/Library/Application Support/ok-helper-tui/config.toml` |
| Windows | `%APPDATA%\ok-helper-tui\config.toml` |

```toml
root_dir        = '~/Tracks'
downloads_dir   = '~/Downloads'
watch_downloads = false
theme           = 'auto'

ftp_host        = 'ftp.example.com'
ftp_port        = 21
ftp_user        = 'username'
ftp_password    = 'secret'
ftp_path        = '/upload'
ftp_readonly    = false

help_visible_at_start = true
first_run = false
```

Пути пишите в **одинарных** кавычках, если они содержат `\`:

```toml
root_dir = 'C:\Users\you\Tracks'   # правильно
root_dir = "C:\Users\you\Tracks"   # ошибка TOML
```

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest -v
```

Маркеры: `analyzer`, `ftp`, `translit`, `folder`, `path_walk`, `upload`,
`smoke`. Пример: `pytest -m "ftp and smoke"`.

Allure-отчёт:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

CI/CD (`.github/workflows/ci.yml`):

1. Тесты на Ubuntu и Windows, Python 3.11 и 3.12, с Allure.
2. Публикация Allure-отчёта в артефактах и на GitHub Pages.
3. Сборка `.exe` для Windows.
